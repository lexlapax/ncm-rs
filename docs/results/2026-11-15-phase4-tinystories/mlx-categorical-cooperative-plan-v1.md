# Isolated Metal categorical sampling experiment

TinyStories' current Metal inverse-CDF sampler assigns one thread to each 4,096-value row and scans that row serially. Neighboring threads therefore read different, widely separated rows. A diagnostic candidate assigns a 32-thread group to a row, computes the maximum and exponentials cooperatively into threadgroup memory, and lets its leader accumulate the total and prefix in the same index order as the existing sampler. It retains the same supplied 32-bit uniform comparison and invalid-row sentinel. The computation is intended to preserve existing decisions, but its correctness and speed are unproven until checked on real Metal; the [MLX custom-kernel documentation for the pinned release](https://raw.githubusercontent.com/ml-explore/mlx/v0.32.2/docs/src/dev/custom_metal_kernels.rst) describes thread-grid dispatch and contiguous inputs.

Apply `tools/bench/phase4_mlx_categorical_probe.patch` only to a new isolated source copy of the reviewed commit. The patch includes `tools/bench/phase4_mlx_categorical_probe.rs` as a test-only module; it does not change the production checkout. The diagnostic compares every candidate output with the existing kernel on 256 and 16,384 controlled rows, including NaN, positive infinity, all-negative-infinity, a single finite last entry, and edge random words. It then alternates both kernels in one process, with five warmups and 15 measured calls each, for an exploratory timing comparison. It is not an end-to-end or Python performance gate and does not prove equivalence on all possible inputs.

Retain failures and input/source/binary/library fingerprints. If exact outputs differ, the Metal source fails, or the candidate does not show a meaningful speed advantage, do not integrate it. If it looks promising, production integration still needs dedicated edge cases, pinned TinyStories and Sudoku regressions, Linux-before-Metal checks, full quality and end-to-end paired performance/memory validation; no tolerance, RNG stream or upstream pin changes are implied.
