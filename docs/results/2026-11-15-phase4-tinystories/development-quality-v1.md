# TinyStories development quality and held-out criteria

This document freezes the TinyStories held-out quality criteria **before** generating or scoring the official seeds `[42, 0, 1, 2, 3]`. It uses only the separate development seeds `[100, 101, 102, 103, 104]`, 128 samples per seed per runtime, generated at batch 4 on CUDA. Python and Rust intentionally use different random streams. The 1,280 outputs passed re-decoding and re-encoding with the pinned upstream BPE tokenizer. The Rust samples here use the corrected fixed-order categorical scan.

The unmodified upstream GPT-2-large evaluator ran out of GPU memory at its batch size 32. At batch 8, the original scorer found mean per-seed generative perplexity 16.198817 (Python, seed SD 0.564711) and 15.877978 (Rust, SD 0.123156). Mean token entropy was 3.976189 (Python, SD 0.009159) and 3.977567 (Rust, SD 0.009496). The retained raw result is `reports/phase4-tinystories-development-v2/quality-v2.json`, SHA-256 `1dcc729ab7d87ba04fa5048d423fc1012b1cef2a605418276e3a0aef8ab9e8db`.

The memory-bounded scorer runs the transformer with the upstream batch size 32, disables unused KV-cache output and chunks the equivalent output projection/log-softmax. On eight Python and eight Rust development texts at batch 8 it matched every original scorer token count; maximum absolute per-token mean-NLL differences were 0 and `4.806e-7`, below the predeclared `1e-4` limit. Qualification report: `reports/phase4-tinystories-development-v2/stream-qualification-v1.json`, SHA-256 `8639da94eeaa64c7b49fffd9fc47d7024609ccb6d7f1d40ff7e4f9a68c417dfb`. Batch-32 streamed development scoring gave mean PPL 16.198815 (Python, SD 0.564710) and 15.877978 (Rust, SD 0.123156), with the same entropy values. Raw result SHA-256 `d62be0cfca8205570f3adcb13d6291aa584f7059b56e55fa17ced3dee6842104` is in `reports/phase4-tinystories-development-v2/quality-stream-v1.json`. This is a disclosed evaluator implementation change, not a claim that the unmodified batch-32 scorer passed.

For the held-out comparison, require all five official seeds with 256 samples each, valid token/decoding checks, and the qualified batch-32 scorer. Accept the stochastic quality component only if the Rust five-seed mean PPL is no more than **1.15 absolute points above** the Python five-seed mean and the absolute difference of their five-seed mean entropies is at most **0.019 nats**. These round up twice the observed Python development seed SDs (1.12942 PPL and 0.018318 nats); the official set has twice as many samples per seed. This is a pragmatic noise-informed non-inferiority criterion, not a guarantee that all semantic defects are detectable or a statistical confidence interval. Tokenizer and teacher-forced correctness, device performance/memory, real-hardware gates and other Phase 4 profiles remain separate requirements.

The local sample/result files and pinned GPT-2-large evaluator identities are described in [the Phase 4 contract](../../PHASE4-TEXT.md). No held-out quality result is claimed here.
