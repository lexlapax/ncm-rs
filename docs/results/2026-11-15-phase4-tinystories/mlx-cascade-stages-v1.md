# Same-input MLX and CUDA first-level cascade

A retained pinned Python CUDA trace provides 128 first-level embeddings, the outputs of four learned upsampling stages and the residual convolution and blend. MLX was given the exact same captured CUDA input for each individual operation, and a separate path propagated MLX outputs through the cascade. The input trace was hash-verified; source, artifact and reference hashes remained stable.

All four MLX upsampling stages were bit-identical to CUDA in both same-input and propagated comparisons. Given the same stage-3 input, the residual convolution differed bitwise at 6,077,080 of 6,291,456 values; 42 exceeded the existing accumulated diagnostic band, with maximum absolute difference 0.0234375. After the residual blend, 15,618 values exceeded that band, with maximum absolute difference 0.01171875. Same-input and propagated blend results were identical because all preceding stages matched. This localizes an early cross-runtime discrepancy to residual-convolution arithmetic in this probe; it does not establish that the entire generator-logit discrepancy has the same cause or that either FP32 result is closer to exact arithmetic. No tolerance changed.
