CUDA's trait defaults retain the existing composed operations; MLX selects the same measured batch-sensitive paths. The GPU kernel checks SIMD width and provides a scalar reduction for other widths. This does not alter the pinned upstream, artifact, model equations or numerical thresholds. The scalar branch has been forced on the test Mac but not run on actual non-32-wide hardware; a real MLX compiler-cache failure has not been injected.
