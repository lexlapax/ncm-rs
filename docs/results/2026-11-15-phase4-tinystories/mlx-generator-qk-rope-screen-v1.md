# Experimental fused Q/K RMS and rotary: Metal screen

The isolated [candidate](mlx-generator-qk-rope-plan-v1.md) passed the real-Metal operator comparison against the existing composition at batches 1 and 16, using the existing operator diagnostic band. In a seed-42 batch of 128, 39 code rows and 23 decoded texts differed from the compiled-GELU baseline; this is not sample identity.

Five fixed-code traces of 16 rows each matched the same-device Python MLX adaptation within the existing accumulated diagnostic band for all checked generator logits; checked argmaxes, final output IDs and codec codes matched. The maximum normalized error was 0.251. Comparisons with the original pinned Python CUDA traces had 1,131 generator/final-logit elements outside that band, with checked decisions and IDs matching. This cross-runtime limitation is not a pass and no tolerance was changed. Input hashes remained stable.

The five official seeds each generated 256 samples for the same nonblind retest and frozen quality criteria. Both quality criteria pass; every sample passed the pinned upstream tokenizer preflight. The same qualified memory-bounded batch-32 GPT-2-large scorer was used, with its previously documented limitations. Sample capture had CPU activity monitoring but no GPU activity measurement; scoring had before/after GPU snapshots and one interim observation, not continuous telemetry.
