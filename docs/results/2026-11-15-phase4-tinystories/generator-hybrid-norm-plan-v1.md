# Isolated batch-sensitive generator normalization candidate

The unconditional fused-normalization candidate reduced median latency but exceeded Python MLX peak memory at batches 1 and 4 and had a batch-128 tail failure in the [paired comparison](generator-fused-norm-mlx-performance-v1.md). The isolated patch `tools/bench/phase4_generator_hybrid_norm.patch` proposes the existing composed normalization below batch 16 and the same fused operation at batch 16 and above. Both compute the upstream layer-normalization equation; the Metal fused operation can differ in FP32 rounding. The threshold matches the existing Metal Q/K/V layout boundary, but this alone does not prove it is optimal or that intermediate batch sizes are qualified.

Apply the patch only to a new isolated copy. On Linux first, run the pinned CUDA Sudoku generator golden and the existing strict-cuDNN 128-row TinyStories comparison. On Metal, compare small-batch outputs with the retained original implementation and batch-128 outputs with the already quality-scored fused candidate; test batch 16 as the branch boundary. Run a targeted paired small-batch performance/memory screen before deciding whether the added branch is useful. The prior [fused quality retest](generator-fused-norm-quality-v1.md), 80-row fixed-code comparison and large-batch performance results apply only if the corresponding branch and output identities are actually verified; do not assume them. The unresolved batch-128 tail remains a separate failure and this change is not claimed to fix it. Full CUDA-then-Metal validation and repeated Python comparisons are required before integration.

The isolated CUDA candidate passed the pinned Sudoku generator golden and strict-cuDNN 128-row TinyStories code/ID comparison. The watched candidate source, test source and native cuDNN hashes matched before and after; `reports/phase4-hybrid-norm-cuda-v1/test.log` SHA-256 is `a8ca96416fa8b2eff12b654533e94d334879a7e93477a4c85b5229e555a3f929`. This focused screen is not a replacement for full CUDA validation before integration.
