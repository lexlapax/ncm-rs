# Same-position generator outlier diagnostic

Existing 16-row generator traces show similar counts outside the unchanged accumulated CUDA-relative band for Rust MLX and Python MLX, but counts alone do not show whether the same values differ. This bounded diagnostic applies `tools/bench/phase4_trace_overlap.patch` to the existing teacher probe in an isolated source copy. The patch compares each Rust generator value and each retained Python MLX value against the same pinned CUDA value, reporting counts outside in both, only Rust, only Python, or neither. It also counts Rust/Python bit differences. The tool verifies both traces have identical forced codes and codec input IDs, and validates tensor shape, dtype, and finiteness. It does not change model math, weights, numerical bands or production behavior.

Use seed 100's 16 retained rows and fingerprint the source, patch, binary, artifact, native libraries and both reference traces before and after. Check the marginal totals against the existing independently produced Rust-versus-CUDA and Python-MLX-versus-CUDA summaries; report any mismatch rather than accepting it. One seed can characterize overlap for that input but is not a full-profile numerical qualification or proof of causation. The existing CUDA qualification remains applicable because this patch changes only an MLX example in an isolated copy. Local patch replay and Rust formatting checks pass; the [real-Metal result](mlx-outlier-overlap-v1.md) extends the same comparison to all five retained seeds.
