# Rust-only generator outlier magnitudes

The [bounded diagnostic](mlx-rust-only-outliers-plan-v1.md) replayed all five retained 16-row TinyStories inputs on the current Rust Metal model. It recorded the 18 generator values that crossed the unchanged CUDA-relative accumulated band in Rust while the corresponding Python MLX values remained inside. The per-tensor overlap and bit-difference counts exactly reproduced the previous independent [overlap run](mlx-outlier-overlap-v1.md); all inputs, workspace crate and vendored sources, artifact, native libraries and diagnostic binary were stable before and after. External Cargo dependency source was not separately fingerprinted.

The Rust absolute-error-to-band ratios ranged from **1.000036 to 1.060243**, with median 1.005244. The absolute amount above the existing band ranged from `2.625e-8` to `4.265e-5`, with median `5.382e-6`. The absolute Rust-versus-Python-MLX differences at those positions ranged from `1.550e-6` to `6.294e-5`, with median `9.894e-6`. All 18 are band failures under the current contract, despite their proximity to its boundary. These figures do not describe the 1,113 shared outliers or establish the cause of the separate latency tail.

`tools/bench/validate_phase4_rust_outliers.py` independently reconstructed the recorded FP32 values, checked each reported error and band, and required all per-tensor counts to equal the earlier run. A separate CPU read of the retained safetensors at the recorded offsets verified both the CUDA and Python MLX values for all 18 records bit-for-bit. This does not independently reproduce the Rust values or prove parity on other inputs. No tolerances or model algorithms changed.
