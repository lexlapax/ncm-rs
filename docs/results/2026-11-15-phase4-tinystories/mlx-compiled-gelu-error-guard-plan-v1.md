# Compiled GELU initialization error guard

The pinned `mlx-rs` compiler constructor calls `expect` when capturing its compile cache. The [compiled generator GELU candidate](mlx-generator-compiled-gelu-plan-v1.md) therefore needs a defined error path before production use. This isolated follow-up applies the hybrid and compiled-GELU patches, followed by `tools/bench/phase4_compiled_gelu_error_guard.patch`. With Rust panic unwinding enabled, it catches a panic during compiler construction and returns a backend error; it does not silently fall back to eager GELU. Builds configured with `panic=abort` explicitly reject the compiled path before calling the constructor, because such panics cannot be caught. This is a proposed support constraint, not a claim that arbitrary panics or aborts elsewhere are recoverable.

Formatting, a Linux default backend/model check, patch replay, the pinned CUDA Sudoku golden and strict-cuDNN TinyStories retained-output comparison passed. The focused CUDA log `reports/phase4-gelu-safe-cuda-v1.log` has SHA-256 `837d6524dcb5350b5d50930e04793b9d4c7e1dac5badd65ddaf777ddb43bda9d`. The guard changes only the Metal backend; these checks do not replace full CUDA validation.

The separate `tools/bench/phase4_compiled_gelu_abort_probe.patch` adds a feature-gated diagnostic example that requires a `panic=abort` build and checks that the compiled path returns the declared error. Formatting, a default Linux backend/model check and patch replay pass with that example present; its Mac build has not run.

On Metal, the added focused unit test must show that a simulated constructor panic becomes an error, followed by the composed-versus-compiled operator and seeded-output checks. The `panic=abort` example must demonstrate the explicit rejection without invoking the compiler. Actual MLX cache-acquisition failure injection, custom panic hooks and failures outside construction are not covered by the simulation. Full CUDA then Metal checks, numerical/quality evidence and performance validation are still required for the guarded source before integration.
