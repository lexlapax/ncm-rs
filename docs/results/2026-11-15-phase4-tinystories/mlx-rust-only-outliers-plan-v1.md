# Rust-only outlier magnitudes

The five-seed [overlap diagnostic](mlx-outlier-overlap-v1.md) found 18 generator values where Rust MLX was outside the existing CUDA-relative band while Python MLX was inside. Aggregate counts do not reveal how far those values crossed the band. `tools/bench/phase4_trace_outlier_details.patch` extends that isolated diagnostic to record, for each Rust-only value, its flat tensor offset and CUDA, Rust MLX and Python MLX values, existing band and absolute errors. Output is bounded to at most 128 Rust-only values per tensor; exceeding that bound fails rather than truncates. It verifies matching input tensors and preserves the earlier overlap counts and finiteness checks. No production source, device policy or numerical band changes.
