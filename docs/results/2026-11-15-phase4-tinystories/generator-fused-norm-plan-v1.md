# Isolated generator fused-normalization candidate

The shared generator performs two layer normalizations in each of 12 transformer blocks plus one final normalization at each of 11 TinyStories levels: 275 calls per request. It currently uses the general composition. The backend already exposes `layer_norm_accelerated`; its default delegates to the existing operation, while Metal uses the previously tested fused MLX affine layer norm. This candidate switches only the shared generator's normalization dispatch to that existing backend hook. Fused evaluation can change FP32 rounding, so no output identity, numerical parity or performance gain is assumed.

Apply `tools/bench/phase4_generator_fused_norm.patch` to an isolated copy of the reviewed commit. On Linux first, run the pinned Sudoku CUDA generator golden and `tools/bench/phase4_generator_fused_norm_cuda_probe.rs` as an isolated integration test, using the strict-cuDNN TinyStories artifact. That probe compares the raw codes and IDs for the first retained batch of 128 seed-42 samples by SHA-256 over little-endian `u32` values; the expected hashes derive from `reports/phase4-safe-split-cuda-v1/seed42-256.json`. The CUDA accelerated hook currently defaults to the ordinary normalization; the comparison confirms actual candidate execution rather than assuming that default is sufficient.

Only after Linux validation, build the isolated Metal candidate, check the existing fused-vs-composed operator regression, the pinned Sudoku golden and retained TinyStories outputs, and compare it with the preserved baseline at batches 32 and 128. Use unchanged fixed-code references and accumulated diagnostic band if investigating numerical differences. A one-process old/new diagnostic is a screening result, not a Python or full performance gate. Retain failures. Any candidate that is numerically incompatible or lacks a meaningful performance/memory advantage stays isolated; integration requires the full existing CUDA-then-Metal checks, task quality and source-bound paired comparisons. No tolerance, upstream pin or sampling setting is changed.
