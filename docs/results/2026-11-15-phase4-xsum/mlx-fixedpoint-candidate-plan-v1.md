# XSum-only Metal fixed-point sampler candidate

The isolated [32-passage experiment](mlx-fixedpoint-sampler-v1.md) matched an independent FP64 inverse-CDF reference on 6,400 saved draws and reduced same-logit differences versus the CUDA sampler from five to one. This candidate introduces an explicit XSum-only backend sampling hook: CUDA forwards to its existing sampler, Metal uses the experimental 48-bit fixed-point accumulation, and other backends fail explicitly. TinyStories continues to use the original categorical hook and implementation. No RNG stream, artifact, upstream pin or numerical tolerance is changed.

Metal still computes exponentials in FP32 and truncates individual weights below `2^-48`; the maximum accumulated weight is bounded by `2^60`. A zero random word selects the first positive representable weight, and invalid rows retain the sentinel. The test includes exact half-boundary words, zero and maximal words, NaN, positive infinity, all-negative-infinity, invalid shapes, tiny leading weights, and a 256-row independent FP64 comparison. These tests do not establish universal FP64 equivalence, and any result remains scoped to the tested inputs.

Before Metal execution, strict-CUDA seeded CPU-final and device-final generation on the same 32 real prefixes reproduced the earlier CUDA result byte-for-byte (`reports/phase4-xsum-fixedpoint-candidate-cuda-v1.json`). Run the full Linux CUDA suite and strict lint, then pull the reviewed candidate to Mac and run real-Metal categorical tests, the saved shared-history diagnostic and the 32-passage seeded CLI comparison. Preserve the original failures. A candidate pass on these inputs is not yet XSum stochastic quality, complete Metal compatibility or a performance/memory pass; full quality and repeated comparisons remain required.

Linux `tools/check.sh --cuda` passed, including 18 real CUDA operator cases (`reports/phase4-xsum-fixedpoint-candidate-linux-v1.log`), and strict-cuDNN backend/CLI Clippy passed with warnings denied (`reports/phase4-xsum-fixedpoint-candidate-strict-clippy-v1.log`). Mac-only tests remain pending.
