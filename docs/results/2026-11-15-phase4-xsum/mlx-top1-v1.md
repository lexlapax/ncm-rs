# Initial XSum Metal top-1 generation

On Apple M1 Ultra at commit `72c905b`, the [Metal top-1 candidate](mlx-top1-plan-v1.md) passed its real-device selector test for unique values, exact ties including signed zero, nonfinite values and invalid shape. For each of the earlier and rotary reference artifact profiles, the two synthetic padded prefixes in the pinned Python CUDA trace produced all 400 generator codes and 96 penalized output IDs exactly. Across each trace, all 6,799,360 floating values were within the existing `atol=5e-4, rtol=2e-4` accumulated band and all 400 head argmax decisions matched. Final penalties were calculated by the explicitly invoked existing CPU FP64 selector.
