# XSum fixed-code teacher comparison on Metal

The first XSum Metal run passed the [fixed-code comparison](mlx-teacher-plan-v1.md) against the pinned Python CUDA trace. Across two padded prefixes and all nine generator and reconstruction levels, all 6,799,360 floating-point values were inside the existing `atol=5e-4, rtol=2e-4` accumulated band. All 400 level-head argmax decisions, 96 raw greedy IDs and 96 CPU-FP64-penalized final IDs matched. The largest absolute difference was 0.0011292 on level-8 generator logits; the combined absolute/relative band still passed. The [per-tensor result](mlx-teacher-v1.json) has SHA-256 `b9785b434674ba5d8dca60859d57e5ed26b6e6468800a9fa7fcbb219de33517c`.

The run used Apple M1 Ultra, macOS 26.7.3 (25G416), Homebrew Rust 1.99.1 and repository commit `c4e68ac3338d713fc20ccfa1207796a3a15bbf7e`. The `xsum-phase4-v2` artifact manifest was `5df37749e64418c586472a4678600603992357b9bc5e3611da307918e13b237e`, the CUDA reference trace `c1abac8e03dcfa10d6d14dcee0e9066e1ec30c90e88e96ae856ea1ecd22c7995`, and the release Metal probe binary `42a525d960b13d750f56584a142817c40e4a62ce95be57aadf79eb87ef03f508`. On Mac, with `PATH=/opt/homebrew/bin:$PATH`, `MLX_SYS_PREBUILT=$PWD/.reference/mlx-native`, and `RUSTFLAGS="-C link-arg=-Wl,-rpath,$MLX_SYS_PREBUILT/lib"`, the commands were `cargo build --release --locked -p ncm-backend-mlx --features mlx --example xsum_teacher_probe` and `target/release/examples/xsum_teacher_probe artifacts/canonical/xsum-phase4-v2 reports/phase4-xsum-mlx-teacher-v1/reference.safetensors`. The build and output logs are retained on Mac in `reports/phase4-xsum-mlx-teacher-v1/`, and copied evidence is under local `reports/phase4-xsum-mlx-teacher-captured-v1/`.

Linux `tools/check.sh --cuda` passed before the Mac run, including 18 real-CUDA operator cases (`reports/phase4-xsum-mlx-teacher-prep-linux-v1.log`). This small, fixed-history numerical result does not implement Metal XSum selection or the CLI, and is not a generated-output, task-quality, speed or memory gate. Those remain open; no tolerance changed.
