# XSum stochastic CUDA qualification design

The user chose full stochastic qualification before MLX. This design is recorded before the held-out captures. It does not change the existing deterministic quality rule, floating-point tolerances, upstream pin, or the recorded controlled-draw failures. It applies to temperature 1, top-k 0, top-p 1, CFG 0; it does not qualify other guidance scales.

Use upstream Python CUDA on development rows 0–255, five seeds 100–104, batches of 32. Both runtimes receive batch seed `1000 * seed + batch_index`; upstream uses PyTorch multinomial and Rust uses its SplitMix64 inverse-CDF sampler. These streams are different, so neither matching seeds nor exact text equality is assumed. Score stemmed ROUGE-1/2/L F1 (percentage points), GPT-2 generated-text perplexity and mean output word count with the pinned evaluator. Freeze margins from Python development data alone: twice the sample standard deviation across the five per-seed metrics, rounded upward to 0.01 for each metric. A zero resulting margin makes qualification fail pending investigation. This is a pragmatic, variability-based quality criterion, not an upstream specification or a new floating-point tolerance.

After committing the derived margins and hashes, evaluate fresh rows 256–511 using seeds 42, 0, 1, 2, 3 for both runtimes. Compare five-seed averages. For each of 10,000 bootstrap replicates using NumPy RNG seed 20261116, sample 256 input row indices with replacement, shared between runtimes, and independently sample five seed indices with replacement for each runtime. Compute the seed-mean ROUGE and word count on those rows and, for each seed, perplexity from summed per-row NLL divided by summed token count before averaging seed perplexities. A replicate with no scoreable tokens fails the analysis. Calculate degradation as Python minus Rust for each ROUGE, Rust minus Python for perplexity, and absolute Rust–Python difference for mean words. The 95th percentile of each degradation must be no greater than its corresponding frozen margin; the absolute word-count statistic gives a two-sided magnitude bound. Report observed differences, bootstrap bounds, all seed metrics and any failure without adapting margins after seeing held-out results. Bootstrap intervals describe only the chosen rows and random-seed design; five seeds cannot establish universal equivalence.

Qualification also requires the existing source-bound controlled-draw investigation, successful held-out capture and scorer integrity checks, and separate repeated, activity-observed CUDA latency, process RSS and sampled driver GPU-memory comparisons. Rust must beat Python in both latency and memory according to the project gate. The prior exploratory data and the known exact full-model decision differences remain visible. Linux must pass before MLX work begins.
