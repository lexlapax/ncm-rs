# Independent XSum stochastic follow-up

The original five-seed, 256-row [held-out quality comparison failed](stochastic-heldout-v1.md). Its post-hoc [uncertainty decomposition](stochastic-uncertainty-v1.md) found material contributions from both row and seed variation. This follow-up was chosen **after seeing that result**; it cannot turn the original failure into a pass or be presented as a single preplanned one-look study. Its purpose is to collect independent, more precise evidence for review without loosening the original margins.

Before generating or scoring follow-up outputs, freeze [this protocol](stochastic-followup-protocol-v1.json), SHA-256 `8ccd05295382f6ad33b17183a3f24e5d726da74a73fc1a7027eea81af10d5332`. It retains the original Python-derived margins and all sampling/evaluator settings, and selects previously unused dataset rows 512–2559 (2,048 rows) and five new seeds 4–8 for both runtimes. Inputs are processed in batches of 32; batch seed is `1000 * seed + batch_index`. Capture separate raw IDs, source fingerprints and per-row scores as in the original study. Python and Rust streams remain independent.

Use 10,000 bootstrap draws, with shared row indices and independently resampled runtime seed indices as before. Compare mean seed ROUGE, mean seed generated-text perplexity and mean word count with exactly the original absolute margins. Report observed differences and the **97.5th percentile** degradation bounds; require each bound to be at most its frozen margin. For word count use the absolute difference. The more stringent bound acknowledges this additional look but does not by itself repair the original failed test, establish a global familywise error rate, or guarantee that a follow-up pass proves universal equivalence. Retain and report both studies; do not select or alter criteria based on follow-up outcomes. If this follow-up fails or indicates a meaningful regression, investigate rather than silently add further attempts.

The scripts are copies of the source-bound first-study tools restricted to this fresh row and seed range, with the analysis bound strengthened and the original protocol's margin hash checked. Syntax, changed-margin rejection and a synthetic injected-regression bootstrap check passed before capture. GPU capture, scoring and analysis remain pending. The original exact controlled-draw differences and the separate stochastic performance evidence remain unchanged.
