# Accepted Apple immediate-memory exception

The user was presented with the existing Phase 2 1.05 steady-state live-memory limit, the measured immediate Apple batch-four resident-block snapshot of **69,702,948 bytes**, or **1.058744×** previous Rust (**65,835,532 bytes**), and the observation that active bytes settled near parity after an additional barrier. The presented alternatives were to keep seeking a faster fix or accept the documented immediate-memory exception; the user replied **“accept it.”** This records that explicit decision for the observed immediate snapshot on the qualified Apple runtime. It is an exception, not a claim that this snapshot meets 1.05 or proof of its exact allocation ownership. The locked [acceptance contract](acceptance-v1.json), numerical tolerances, pins, artifacts and other limits remain unchanged.

The matching adapted-Python immediate snapshot was 65,835,528 bytes, yielding effectively the same ratio. Both comparators and all snapshot stages remain in the [original memory evidence](apple-gate18-results-v1.md). A separate additional stream synchronization reached the lower snapshot but increased batch-four block medians by 10–16% in three exploratory pairs; it was not integrated. The earlier Q/K/V and projection alternatives and their negative or partial results remain retained.

This exception does not waive or redefine host RSS/HWM or any other acceptance cell. The separate batch-four encode **peak active MLX allocation** was 155,866,252 bytes versus 129,751,100 previous-Rust bytes (1.20127×); it is not a host RSS figure or the steady-state live snapshot. A prior isolated comparison attributes a similar roughly 26 MB increase to vectorized linear interpolation while showing a 0.552 latency ratio for that scope. Exact buffer ownership and whole-device physical memory were not established. This observed resource/performance tradeoff is disclosed, not called a 1.05 pass or silently included in the exception. Apple allocation-count and per-request CPU telemetry remain unavailable; energy was not measured.
