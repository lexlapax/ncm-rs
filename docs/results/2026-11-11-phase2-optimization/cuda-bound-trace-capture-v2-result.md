# CUDA trained-trace executable binding

A fresh trained CUDA capture passed all **642 traces and 2,500 decisions**, with zero disagreements and two near ties. Its trace hash and qualification JSON match the earlier gated qualification byte-for-byte. The release `codec_trace` executable, both CUDA fused-projection source files and the artifact manifest had the recorded hashes immediately before and after capture; both subprocesses exited successfully. This is a correctness/provenance observation, not a performance measurement or an immutable-execution proof.

A separate local [build observation](cuda-build-observation-v1.py) found that the current benchmark, trace and lifecycle compiler dependency files list both CUDA fused-projection modules. The benchmark and lifecycle executable hashes match their gate receipts. The depfiles are not cryptographic proof of historical compiler inputs. The previously retained CUDA, Metal and oracle trace arrays match their qualification hashes; the large arrays remain local and are not included in Git. Publication of licensed trace assets requires separate authorization.
