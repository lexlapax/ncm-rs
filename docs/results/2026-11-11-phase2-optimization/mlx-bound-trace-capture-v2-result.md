# Metal trained-trace executable binding

After the CUDA provenance capture, a fresh Metal capture passed **642 traces and 2,500 decisions**, with zero disagreements and two near ties, against the unchanged trained CUDA oracle. The trace hash and qualification JSON match the previously qualified Apple control byte-for-byte. The Mac trace executable, MLX backend and shared-model source files, artifact manifest, native MLX library and metallib had the recorded hashes immediately before and after the capture. The checked source files match candidate `f155794`, and the native library hashes match the earlier Apple control. This is a correctness/provenance observation, not a new performance gate or proof of immutable execution.
