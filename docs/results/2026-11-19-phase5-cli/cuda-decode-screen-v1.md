## LM1B retained CUDA cohort decoding

On 2026-11-20, the same artifact-embedded BERT `decode_lm1b_flm` used by the CLI matched pinned Transformers `batch_decode` on **20,480** retained CUDA Rust output rows for each of small, medium and large (80 seeds, 256 rows per seed; 61,440 rows total). The generator checks the pinned tokenizer source and versions, the respective campaign receipt hash and every capture hash and metadata, then rechecks inputs after decoding. Its references were regenerated byte-for-byte; their SHA-256 values are `e54a4cbe7272fd6c5a92cb5d0b8e638155e1e2e4eedf2f31836b818b8f91efff` (small), `f4111039d11d7ab9142530f7e5543ff07378bce752265381197fcc2c2d5becaa` (medium), and `dcbd89cdbdfac0d9fea13dd57db154655c12ec2ed13926989584ac25e186780e` (large). The ignored Rust test checks those identities, each receipt, each capture and all decoded rows with the corresponding authenticated artifact tokenizer. All three tests passed; a modified small reference failed its hash check. `tools/check.sh` passed, including generator output-preflight tests.

The first attempt used a non-exact Rust test filter that also selected three unrelated ignored tests without their environment variables; those three failed before reading inputs while the LM1B small test passed. The corrected exact filter below passed separately for all sizes. Raw cohort captures and decoded references remain ignored under `reports/`; see the [small](cuda-lm1b-small-quality-retest-v1.md), [medium](cuda-lm1b-medium-quality-retest-v1.md), and [large](cuda-lm1b-large-quality-retest-v1.md) retests for capture provenance. This is a host-side decoder comparison, not CLI cohort-equivalence, new inference, or Metal validation; no runtime code changed.

```sh
for size in small medium large; do
  setpriv --inh-caps=-all .reference/tokenizers-venv/bin/python tools/reference/phase5_lm1b_retained_decode.py "$size" "reports/NEW-$size-reference.json"
  setpriv --inh-caps=-all env NCM_LM1B_SIZE="$size" \
    NCM_LM1B_ARTIFACT="$PWD/artifacts/canonical/lm1b-$size-inference-v1" \
    NCM_LM1B_CAPTURES="$PWD/reports/phase5-lm1b-$size-cuda-retest-v1/rust" \
    NCM_LM1B_DECODE_REFERENCE="$PWD/reports/NEW-$size-reference.json" \
    cargo test --locked -p ncm-cli --bin ncm lm1b::dispatch_tests::retained_corpus_decode_matches_pinned_evaluator -- --ignored --exact
done
```
